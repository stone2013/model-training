网络结构：16×16 RGB 输入 → 4 个 3×3 卷积核 + ReLU → 2×2 MaxPool → 全连接 → Softmax。训练全在浏览器本地执行，不调用服务器。验证集按图片 ID 和固定种子划分，重复训练时样本不漂移。组合图检测会排除“背景 / 非目标”类，并用置信度和类别差距拒绝不确定区域；建议为背景类添加不含目标的图块。每类建议至少 20–50 张不同图片。
