# CNN Lab · 浏览器图片分类训练器

纯前端图片分类训练器：自定义类别、在浏览器内训练 CNN、导入/导出模型，并用多尺度滑动窗口扫描组合图片。

## 本地运行

在项目目录启动静态服务器（ES modules 不能直接从 `file://` 页面加载）：

```bash
python3 -m http.server 8000
```

浏览器打开 `http://localhost:8000`。图片处理、训练和扫描均在浏览器本地完成，不会上传图片或调用训练服务器。

## 这次改进

- 上传开始时捕获类别索引，因此图片解码期间切换类别不会改掉这批图片的标签。
- 每个样本有稳定 ID；验证集按固定种子和 ID 划分。连续点“训练 1 轮”会沿用同一数据集切分，新增图片后再按新数据集确定切分。
- 模型输入改为 16×16 RGB，保留颜色信息；旧灰度模型导入时会迁移第一层卷积权重。
- 可添加“背景 / 非目标”类并上传没有目标的图块。扫描时背景类始终被排除，同时使用置信度阈值和第一、第二类别的概率差拒绝模糊窗口。
- 增加 Node.js 回归测试：上传标签快照、固定验证划分、模型导出/导入、灰度模型迁移、背景/不确定窗口拒判。
