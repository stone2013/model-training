# CNN Lab · 浏览器图片分类训练器

纯前端图片分类训练器：自定义类别、在浏览器内训练 CNN、导入/导出模型，并用多尺度滑动窗口扫描组合图片。

## 本地运行

在项目目录启动静态服务器（ES modules 不能直接从 `file://` 页面加载）：

```bash
python3 -m http.server 8000
```

浏览器打开 `http://localhost:8000`。图片处理、训练和扫描均在浏览器本地完成，不会上传图片或调用训练服务器。

## 这次改进

- 上传开始时捕获类别索引，因此图片解码期间切换类别不会改掉这批图片的标签。
- 每个样本有稳定 ID；验证集按固定种子和 ID 划分。连续点“训练 1 轮”会沿用同一数据集切分，新增图片后再按新数据集确定切分。
- 模型输入改为 16×16 RGB，保留颜色信息；旧灰度模型导入时会迁移第一层卷积权重。
- 可添加“背景 / 非目标”类并上传没有目标的图块。扫描时背景类始终被排除，同时使用置信度阈值和第一、第二类别的概率差拒绝模糊窗口。
- 增加 Node.js 回归测试：上传标签快照、固定验证划分、模型导出/导入、灰度模型迁移、背景/不确定窗口拒判。

## 背景拒识与独立评估补充（2026-10-08）

- 训练要求至少有一个带样本的背景类别。点击“困难负样本”直接选中背景类并上传桌面、墙壁、空白区域等图片；图片必须不包含任何目标。背景不是万能拒识器，仍需实际负样本与独立测试。
- 全图训练、独立分类、滑动窗口统一使用黑色补边、保持比例和 RGB 归一化。检测和背景场景评估共享窗口生成、阈值筛选和同类别 NMS。
- 独立测试区使用左侧当前类别作为真值；测试样本与训练数据分开。评估显示分类混淆矩阵（行是真值、列是预测，包含拒识列）、背景图块误检数，并导出 JSON 报告。目标被拒识算错误，背景被拒识算正确。
- 勾选“整张为纯背景场景”可测量组合图误检框数及出现误检的图片数。不能用含目标图片作为纯背景；没有框标注时不报告定位精度或召回率。扫描界面的拒绝窗口数不是误检数。
- 导入模型清空旧训练和测试数据，避免新类别顺序与旧标签错位；检查模型维度、有限数值和类别唯一性。原有灰度权重迁移仍保留。
- 合成回归测试共 10 项通过，`node --check app.js` 和 `git diff --check` 通过。没有原来 200 张真实图片集，未验证 54.5% 基线的改善。

### 比较方法

准备同一套不参与训练的目标图片、背景图块和纯背景场景。每次载入模型后，按相同类别重新添加测试图，以相同置信度、类别差距和窗口大小评估并保存报告。旧无背景模型需要先用负样本重新训练，单纯加入类别名不能生成背景能力。

### 测试范围

Node 回归覆盖上传类别快照、稳定验证切分、参数往返和灰度迁移、背景与低置信度拒识、统一预处理变换、拒识混淆矩阵、类别映射、多目标候选框 NMS、非法模型及窗口边界。合成概率与模拟 Canvas 测试不是浏览器完整交互验收，也不是实物分类性能测试。
